# Bootstrap subset

The implemented language subset is the empty set: this compiler accepts no
program yet. A construct may be added only with working compiler support and
an executable regression row. Parser acceptance alone is not compilation.

`tools/check-subset` currently checks exact token profiles for the refusal-only
frame driver and its front-end/backend stubs. It ignores whitespace and
comments, but hashes every identifier, literal, operator and punctuation token,
checks the hashes below, and rejects any additional or missing Wolf files.
This bootstrap exception is not a claim that fenrir compiles its driver.
The gate is linear in source bytes and is deliberately not a parser.

When the compiler can compile source, replace the exception with a documented
construct whitelist using the parser; preserve the planted rejection tests.
During bootstrap, an expanded token profile must name its implementation test
and must continue to say that no compiler support is implied.
