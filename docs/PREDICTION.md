# Frame prediction

The initial driver refuses every invocation with status 2 and the text
`fenrir: nothing to compile yet`. It compiles no Wolf language constructs.

The generated pins should reproduce all downloaded bytes after two independent
SHA-256 reads. Changing any pinned byte must fail fetching before extraction.
The differential harness should enumerate every entry in the pinned corpus,
exclude module members explicitly, preserve both oracle observations, and
compute coverage from dynamic outcomes only. Refusals must never score as same.

The empty compiler subset permits only the exact frame driver as a bootstrap
exception. Any other source must fail until an implemented construct is added
to the subset. An unknown emitted diagnostic and an unused catalog code must
both fail. Two identical builds should compare equal; a changed byte must fail.
Strict mode must print and reject a skip. Tests will plant each of these faults.
Linux and macOS should build and run the frame; only Linux records the oracle.
